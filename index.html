我的工具

如果对工具的功能有改进意见，可以从GitHub仓库下载原文件，使用VS Code或其他编程工具自行修改
🔗 GitHub
  • 📅 时间轴
    简易时间轴制作工具，可一键导出图片。 使用方法 1、点击“添加事件”，填写时间（年份必填，月份和日期选填）、事件名称和事件简介（选填）。 2、调整字体大小、图片宽度、背景色、主轴颜色、主轴位置等样式。 3、点击“导出图片”保存为PNG，或“导出配置”备份JSON文件，下次导入JSON文件即可继续填写。
  • 📅 时间轴（通用版）
    时间轴的通用版，可用于农历和架空世界的历法等，完全自定义排序。 注意，两个时间轴工具导出的JSON文件不互通。
  • ❤️ CP连线图
    CP连线图制作工具，可一键导出图片。 使用方法 1、上传图片（可拖拽调整截取区域）或输入角色名添加纯文字头像，建议不超过28个。 2、在角色列表中拖拽 ☰ 调整顺序，可勾选“设为中心”将一个角色置于圆心。 3、添加自定义图例，可拖拽 ☰ 调整顺序，点击 ✕ 删除。 4、拖动滑块调整大圈半径和角色之间的间隔。 5、点击“导出为图片”保存为 PNG。
